# College Internship Management System
## Master Project Documentation

---

### 1. Project Overview & Features
This platform is a comprehensive system designed to bridge the gap between students, employers, and faculty, managed by system administrators.

**Student Portal**
* Application Tracker: Visual timeline of submitted, shortlisted, and accepted applications.
* Job Board: Search, filter, and apply to approved internships.
* Application Modals: Enforced Cover Letter and Key Qualifications text fields.
* Profile Management: Resume Upload zone (PDF & 5MB size validation) and Account Deactivation.
* Feedback System: 5-star rating matrix evaluating Company Culture, Mentorship, Tech Learning, and Work Environment.

**Company Portal**
* Active Postings: View, Edit, and Archive posted internship opportunities.
* Kanban Review Board: Drag-and-drop style application review.
* Interview Scheduler: Strict calendar input that enforces a minimum 24-hour notice rule.
* Evaluation Forms: Reciprocal 6-trait evaluation forms grading students on Technical Skills, Soft Skills, and Punctuality.

**Faculty Portal**
* Department Postings: Faculty-exclusive internship creation pipeline.
* Academic Evaluations: Dedicated forms evaluating "Suitability for Course Objectives".
* Feedback Response Center: UI for Faculty to read student feedback and submit replies.
* Report Generation: 1-click PDF export detailing total students placed.

**Admin Portal**
* System Health KPIs: Real-time metrics on Placement Rates and Active Internships.
* Internship Approval Queue: Manual review gate preventing unverified companies from posting.
* User Management: Invite, Edit, Deactivate, and Bulk Export user accounts.
* Bug Tracker: Built-in "System Feedback" Kanban board to track and mark feature requests.

### 2. Technical Stack & Architecture

* Framework: Next.js 14+ (App Router)
* Styling & UI: Tailwind CSS, Framer Motion, Lucide React
* Database: SQLite (dev.db)
* ORM: Prisma Client
* Authentication: NextAuth.js (Custom Credentials Provider)
* Security: bcryptjs (Password Hashing), Next.js Middleware (RBAC)

**Database Schema (Prisma)**
* User Model: Core authentication table handling email, passwordHash, and role.
* Profile Extensions (1-to-1): Student and Faculty profiles linked to User(userId).
* Company Model (1-to-Many): Stores registrationNumber (Unique), location, and contactPerson.
* Internship Model (Many-to-Many via Application): Stores title, durationWeeks, stipend, and dates.
* Application Model: The pivot table connecting Student and Internship.
* Interview Model (1-to-Many from Application): Stores scheduledAt, interviewerDetails, results, and feedback.

**Backend Infrastructure**
* Authentication Strategy: JWT (JSON Web Tokens) via Custom CredentialsProvider.
* Registration Pipeline: Extracts data, salts passwords using bcrypt.hash(), and uses Prisma's nested create feature to generate the master User record and corresponding profile simultaneously.
* Route Protection: Global Next.js Edge Middleware intercepts requests, decodes the JWT, and verifies the token.role before allowing access to restricted dashboards.
